> **버전:** 1.0.0
> **작성일:** 2026-04-01
> **상태:** ✅ Approved (확정됨)

---

## 1. 🎯 프로젝트 개요 (Project Overview)
이 프로젝트는 AI 기술을 활용하여 현대인들의 지친 마음을 돌보는 개인 맞춤형 심리상담 서비스를 제공합니다.
- **배경:** 현대사회에서 심리 상담의 장벽(시간, 비용, 거부감)을 낮추기 위해 언제 어디서나 접근 가능한 AI 상담사가 필요합니다.
- **목표:** 공감 중심의 대화와 감정 분석을 통해 사용자의 정서적 안정을 돕고, 위기 상황을 감지하여 적절한 도움을 제공합니다.
- **문제 정의:** 기존 상담 서비스는 예약이 번거롭고 비용이 높으며, 단순 챗봇은 공감 능력이 부족하거나 위험한 발언을 필터링하지 못하는 문제가 있습니다.

---

## 2. 👥 타겟 사용자 (Target Audience)
제품을 사용할 주요 사용자층을 정의합니다.
1. **일반 사용자:** 일상적인 스트레스, 불안, 우울감을 겪으며 누군가와 대화하고 싶은 20~40대.
2. **상담 데이터 관리자:** 익명화된 상담 통계를 확인하고 시스템 품질을 모니터링하는 관리자.

---

## 3. ✨ 핵심 기능 (Key Features)

| 기능 ID | 기능명 | 설명 | 우선순위 |
| :--- | :--- | :--- | :--- |
| **F01** | 공감 중심 AI 상담 | Gemini API를 활용한 다국어 및 문맥 인식 공감 대화 | 🔥 High |
| **F02** | 감정 분석 리포트 | 대화 내용을 분석하여 오늘의 감정 상태를 수치화 및 시각화 | ⚡ Medium |

| **F04** | 문맥 유지 대화 | Redis를 이용한 과거 상담 내용을 기억하여 이어지는 대화 제공 | ⚡ Medium |

## 4. 🛠️ 기술 요구사항 (Technical Requirements)
사용할 기술 스택 및 개발 환경을 정의합니다.

- **Frontend:** Next.js 14 (App Router), TypeScript, Vanilla CSS/Glassmorphism
- **Backend:** Node.js, Gemini API (Google Generative AI SDK)
- **Database:** Redis (Context Storage), LocalStorage for local state
- **Design:** Modern Premium UI, Dark Mode support, Interactive Animations

---

## 5. 🗺️ 사용자 흐름 (User Flow)
사용자가 앱에서 경험하게 될 주요 흐름을 단계별로 정의합니다.
1. **진입:** 사용자가 웹사이트에 접속하여 따뜻한 환영 메시지를 받음.
2. **상담 시작:** 고민이나 오늘 하루에 대해 자유롭게 대화 시작.
3. **결과:** 대화 종료 시 오늘의 감정 분석 리포트 및 따뜻한 격려 메시지 확인.
